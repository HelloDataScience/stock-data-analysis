# 파이썬을 활용한 주식 데이터 분석

파이썬으로 **주식 데이터를 수집하고, 전처리하고, 분석 지표를 계산해 시각화하는 과정**을 처음부터 끝까지 따라 하는 강의 자료입니다.

2026년에 부산 지역 취업준비생과 재직자를 대상으로 진행한 강의에서 사용한 강의안(PDF)과 실습 노트북을 정리했습니다. 프로그래밍 경험이 거의 없어도 시작할 수 있도록 최소한의 Python 기초부터 다루고, 실습은 별도 설치가 필요 없는 **Google Colab**에서 진행합니다.

## 이런 분께 권합니다

- 파이썬을 처음 배우거나 기초만 조금 아는 분
- 주식 데이터가 어떤 구조로 되어 있는지 이해하고 직접 다뤄보고 싶은 분
- 수익률, 변동성, 이동 평균 같은 기본 지표를 코드로 계산해보고 싶은 분
- 금융·증권 분야 취업을 준비하면서 데이터 분석 역량을 쌓고 싶은 분

## 강의 내용

강의안 [BIFC Python Stock Data Analysis.pdf](note/BIFC%20Python%20Stock%20Data%20Analysis.pdf)(100쪽)는 다음 순서로 구성되어 있습니다.

| 순서 | 주제 | 주요 내용 | 실습 노트북 |
|:---:|:---|:---|:---|
| 1 | 최소한의 Python 기초 | Python의 특징, Excel과 Python 비교, Colab 사용법, 파일 읽고 저장하기, 구글 드라이브 연결 | [1 Colab Manual](code/1%20Colab%20Manual.ipynb) |
| 2 | 주식 데이터의 이해 | 시계열 데이터와 횡단면 데이터, 주식 데이터의 구성 요소(OHLCV), 날짜 인덱스의 중요성 | - |
| 3 | 크롬 개발자 도구 활용법 | HTTP 통신 리소스 찾기, HTML 요소와 CSS 선택자 찾기 | - |
| 4 | 웹 스크레이핑 실습 | requests와 BeautifulSoup으로 네이버 증권에서 현재 주가 수집, 여러 종목을 수집하는 함수 만들기 | [2 Naver Stock Price](code/2%20Naver%20Stock%20Price.ipynb) |
| 5 | 주식 데이터 수집 및 전처리 | yfinance로 일별 주가 수집, 수정 종가, 날짜 인덱스 전처리와 필터링, 결측값 처리, 집계 함수 | [3 Stock Data Preprocessing](code/3%20Stock%20Data%20Preprocessing.ipynb) |
| 6 | 주식 데이터 분석 지표 계산 | 단순 수익률과 로그 수익률, 일간·누적 수익률, 변동성, 이동 평균 | (위와 같은 노트북) |
| 7 | 주식 데이터 시각화 | 좋은 시각화의 조건과 색 사용 전략, 종가·이동 평균·누적 수익률 선 그래프, 히스토그램, Q-Q Plot, 이동 변동성 | (위와 같은 노트북) |

실습 예제는 삼성전자(종목코드 005930)를 기준으로 작성되어 있습니다. 종목코드만 바꾸면 관심 있는 다른 종목으로도 같은 분석을 해볼 수 있습니다.

## 실습 방법

별도 프로그램 설치 없이 **Google 계정**만 있으면 됩니다.

1. 이 페이지 위쪽의 초록색 **Code → Download ZIP** 버튼을 눌러 파일을 내려받고 압축을 풉니다.
2. [Google Colab](https://colab.research.google.com/?hl=ko)에 접속해 **파일 → 노트 업로드**를 선택하고 `code` 폴더의 노트북을 엽니다.
3. `note` 폴더의 강의안 PDF를 함께 보면서 노트북의 셀을 위에서부터 차례로 실행합니다.

노트북에는 실행 결과가 저장되어 있지 않으므로, 셀을 직접 실행하며 결과를 확인합니다.

## 실습 전 확인할 점

- **웹 페이지 구조 변경**: 2번 노트북은 네이버 증권 페이지에서 데이터를 수집합니다. 사이트 구조가 바뀌면 CSS 선택자를 수정해야 코드가 정상 동작합니다. 강의안의 '크롬 개발자 도구 활용법'을 참고해 바뀐 위치를 직접 찾아보는 연습으로 활용해보세요.
- **yfinance 데이터**: 3번 노트북은 2020년 1월 1일부터 실행 시점까지의 주가를 내려받으므로, 실행 시점에 따라 결과 수치가 강의안과 다를 수 있습니다.
- **한글 폰트**: 그래프에 한글을 표시하기 위해 3번 노트북에서 Colab에 나눔 폰트를 설치합니다. 런타임을 새로 연결하면 설치한 폰트도 사라지므로, 그때는 폰트 설치 셀을 다시 실행해야 합니다.
- **수익률의 의미**: 이 강의에서 계산하는 수익률은 종가 기준 가격 수익률이며, 실제 매매 체결 가격을 기준으로 하는 투자 수익률과는 다릅니다. 강의 내용은 데이터 분석 학습용이며 투자 권유가 아닙니다.
